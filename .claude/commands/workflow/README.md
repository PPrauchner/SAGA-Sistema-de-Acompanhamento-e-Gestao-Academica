# Workflow

Commands específicos do workflow do projeto SAGA.

- **[commit](./commit/SKILL.md)** — Analisa mudanças não-commitadas e realiza commits atômicos seguindo as convenções do projeto.
- **[start-issue](./start-issue/SKILL.md)** — Inicia o trabalho em uma issue do GitHub, avalia complexidade e cria sub-tarefas se necessário.
- **[review-pr](./review-pr/SKILL.md)** — Revisa um Pull Request contra a issue e os specs relevantes, gera relatório e executa a ação escolhida.
- **[review-issue](./review-issue/SKILL.md)** — Analisa o estado de uma issue — o que foi pedido vs. o que foi entregue — e gera relatório de conformidade.
- **[update-doc](./update-doc/SKILL.md)** — Adiciona um relatório ao Google Doc acumulativo do projeto.
